# 🌊 Flood and Landslide Monitoring System Using Machine Learning

## 📌 Overview

The Flood and Landslide Monitoring System is a machine learning-based project designed to predict potential flood and landslide risks using environmental and weather-related data.

The system combines **Convolutional Neural Networks (CNN)** for feature extraction and **Logistic Regression** for risk classification. It processes relevant input data to estimate risk levels and supports disaster awareness through a web-based application.

## 🎯 Objectives

- Predict potential flood and landslide risks using machine learning.
- Analyze weather and environmental factors associated with natural disasters.
- Extract relevant features using CNN.
- Classify risk using Logistic Regression.
- Generate predictions to support early awareness and disaster preparedness.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning:** CNN, Logistic Regression
- **Libraries:** TensorFlow, Keras, Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Web Framework:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **Development Environment:** Jupyter Notebook, Python IDE

## ⚙️ Key Features

### 1. Data Preprocessing
- Handles missing values and prepares input data.
- Performs data cleaning and normalization.
- Transforms data into a suitable format for model training and prediction.

### 2. Feature Extraction Using CNN
- Uses a CNN-based approach to extract relevant patterns and features from the input data.
- Provides extracted features for the classification stage.

### 3. Risk Classification Using Logistic Regression
- Uses Logistic Regression to classify risk based on extracted features.
- Produces predictions that can be mapped to predefined risk categories.

### 4. Prediction and Alert Generation
- Processes input data to generate risk predictions.
- Presents prediction results through the application interface.
- Supports risk awareness and disaster preparedness.

### 5. Web-Based Interface
- Uses Flask to provide a web interface for interacting with the prediction system.
- Displays prediction results in an accessible format.

## 🚀 Getting Started

### Prerequisites

Install Python and the libraries required by the project.

### 1. Clone the Repository

```bash
git clone https://github.com/kartikN1234/Flood-and-landslide.git
```

### 2. Navigate to the Project Directory

```bash
cd Flood-and-landslide
```

### 3. Install Dependencies

```bash
pip install pandas numpy scikit-learn tensorflow flask requests
```

### 4. Prepare the Dataset

Ensure that the training and testing datasets are available in the locations expected by the application.

### 5. Run the Application

Follow the installation instructions in the project documentation to configure the environment and launch the Flask application.
